# Source Code Overview

This directory contains the core logic for the Account Aggregator pipeline. The architecture is modular, separating the heavy data processing engine from the utility scripts and the Streamlit frontend.

## Directory Structure

* **`engine/`**: The core brain of the pipeline. Contains modules for data aggregation, text normalization, exact deterministic matching, and vector-based semantic search.
* **`utils/`**: Helper scripts and text cleaning utilities that support the engine's processing.

Navigate into each directory to view specific `README.md` files detailing their respective modules.
